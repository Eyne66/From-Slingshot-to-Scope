一个关于学习、AI 工具与自我校准的中文交互随笔。来自一次考研英语真题复盘：工具越来越强，我有没有看得更清楚？

## 怎样体验

1. 在“弹弓”阶段试着瞄准几次，观察落点。
2. 切换到“枪”。瞄准点保持原位，落点更集中，比较它们是否仍偏向同一个方向。
3. 切换到“瞄准镜”。目标变清晰，点击图面或拖动滑块调整瞄准点，再观察下一次落点。
4. 到页面下方，带走一个与自己的学习或行动有关的复盘问题。

手机可以点击图面或使用滑块；键盘可以通过 Tab 选中控件、方向键调整滑块。重置按钮会清空尝试并回到第一阶段。

## 项目缘起

这个项目来自一次真实的学习复盘。

做考研英语真题时，我开始留意自己会如何被误导：熟悉感、假线索、先入为主，以及工具制造的“我好像懂了”的感觉。

于是，我把这种经历转化为一个隐喻：

> 从“弹弓期”到“拿到枪但仍然模糊”，再到“拥有瞄准镜”。

我想把一次学习复盘里的感受，整理成可以被观看、操作和追问的网页。项目由我提出想法，与 AI 一起完成代码实现。

## 三个阶段

| 阶段 | 画面中发生什么 | 留下的问题 |
| --- | --- | --- |
| 弹弓 | 目标模糊，落点分散 | 我到底在瞄准什么？ |
| 枪 | 落点更集中，原来的瞄准方向被保留 | 工具升级之后，目标判断有没有同步升级？ |
| 瞄准镜 | 目标清晰，能看见最近落点与靶心之间的偏差 | 我为什么会错？下一次可以怎样调整？ |

这是一个简化的隐喻模型，**不测量认知能力，也不预测真实学习表现**。三个阶段使用同一组循环扰动；“枪”与“瞄准镜”的工具精度相同。切换到瞄准镜不会自动修正方向，调整之后也仍有小幅波动。

## 这次呈现更新

- 互动放到第一屏，采用明亮的蓝白版面，适配手机与电脑。
- “试着瞄准一次”会产生实际落点，保留当前阶段最近 12 个落点。
- 三个阶段分别保留尝试记录，切换时保留瞄准位置，方便比较。
- 复盘问题依次切换，避免连续随机出现同一个问题。
- 保留项目缘起，减少重复说明，加入直接体验与下载入口。

## 继续编辑

`index.html` 包含页面、样式和互动逻辑，不需要安装依赖，也不调用外部 API。

- 修改文字：编辑 HTML 正文与 `STAGES`、`QUESTIONS`。
- 修改视觉：编辑页面顶部的 CSS。
- 修改示意规则：编辑 `STAGES` 的工具分散参数与 `NOISE`。
- `dist/index.html` 是同一页面的发布副本；修改后需同步，再发布站点。
- `.openai/hosting.json` 记录 Sites 站点身份与发布目录。
