# 从弹弓到瞄准镜 / From Slingshot to Scope

来自一次感悟：工具越来越强，我有没有看得更清楚？

**[在线体验 →](https://eyne-slingshot-to-scope.bouncy-wren-3789.chatgpt.site)** · [下载项目](https://github.com/Eyne66/From-Slingshot-to-Scope/archive/refs/heads/main.zip)

## 使用

点击弹弓、枪或瞄准镜，切换第一视角。移动鼠标或拖动镜片调整位置，轻点场景或点击“发射”。

| 工具 | 视野 |
| --- | --- |
| 弹弓 | 白茫茫，看不见靶位、光点或落点 |
| 枪 | 场景清楚，多个呼吸点干扰判断，没有准星或轨迹线 |
| 瞄准镜 | 镜片内清晰放大，可以辨认金色靶心并瞄准 |

瞄准镜阶段成功命中会触发一次满屏飘落庆祝。点击“再试一次”开始新一轮；重置按钮回到弹弓阶段。

支持手机触控。键盘可聚焦场景后用方向键调整，空格或回车发射；页面也提供调整滑块。减少动态效果的系统设置会关闭飘落动画。

## 说明

这是一套隐喻体验，不测量个人能力。切换工具不会自动调整瞄准位置。

网页无需安装依赖，也不调用外部 API。下载解压后打开 `index.html` 即可使用。三个工具各使用独立的透明图片，位于 `assets/`。发布文件位于 `dist/`。
