# 从弹弓到瞄准镜 / From Slingshot to Scope

一个关于学习、AI 工具与自我校准的中文交互随笔。来自一次感悟：工具越来越强，我有没有看得更清楚？

**[下载体验 →](https://github.com/Eyne66/From-Slingshot-to-Scope/archive/refs/heads/main.zip)** · [查看网页源码](https://github.com/Eyne66/From-Slingshot-to-Scope/blob/main/index.html)

解压后双击 `index.html`，在浏览器中打开。

## 使用

点击工具物像切换阶段，再点击“试着瞄准一次”观察落点。点击图面或拖动滑块调整瞄准位置。

| 工具 | 表现 |
| --- | --- |
| 弹弓 | 工具简单，目标模糊，落点分散 |
| 枪 | 工具增强，落点更集中，瞄准方向保留 |
| 瞄准镜 | 目标清楚，偏差显现，可以主动调整方向 |

切换阶段会保留瞄准位置与各阶段的尝试记录；重置按钮清空整个实验。支持手机点击和键盘操作。

页面下方可以切换复盘问题。

## 说明

这是一套隐喻示意，不测量个人能力。“枪”和“瞄准镜”使用相同的工具精度；瞄准镜改变视野，方向由使用者调整。

网页无需安装依赖，不调用外部 API。页面与互动代码位于 `index.html`，物像位于 `assets/`。发布副本位于 `dist/`，修改后需同步。
